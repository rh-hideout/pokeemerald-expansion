# Team Docs

| Doc | For | Use it when |
|---|---|---|
| [ONBOARDING.md](ONBOARDING.md) | Everyone | Setting up a new computer (once) |
| [DAILY_WORKFLOW.md](DAILY_WORKFLOW.md) | Everyone | Every time you work on the hack |
| [MAINTAINER_WORKFLOW.md](MAINTAINER_WORKFLOW.md) | Maintainer | Adding teammates, reviewing PRs, updates, releases |

**Keeping them in sync:** friend-facing steps live in ONBOARDING and DAILY_WORKFLOW.
MAINTAINER_WORKFLOW links to the matching friend step wherever the two depend on each other
(for example, inviting a teammate ↔ accepting the invite). When you change one side, check the other.
